# 鲸鱼娘钱包（DeepSeek余额查询）| Whale Purse for Operit

一只趴在 Operit 侧边栏的鲸鱼娘桌宠，紧盯你的 DeepSeek API 余额，余额告急时用黄色 / 红色气泡提醒你。

## 功能

- 🐋 鲸鱼桌宠：随波摇摆、点击互动弹跳
- 💰 余额监控：点击鲸鱼立即刷新，每 30 秒自动刷新
- 🚨 分级警示：余额低于告警额度显示黄色气泡、低于告急额度显示红色气泡（默认：告警 10 元 / 告急 5 元）
- ⚙️ 额度自定义：点击右下角齿轮设置告警 / 告急额度
- 🔑 自动读取 Operit 已配置的 DeepSeek API Key，无需手动配置
- 🌗 深色模式自动适配

## 安装

1. 在 Releases 中下载 `com.operit.whale_purse-v1.1.0.toolpkg`
2. 导入 Operit 并启用，在侧边栏打开即可
